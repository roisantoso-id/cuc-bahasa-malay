「马来语高频词」小程序改版：三个方向

每个方向 6 屏（首页、词卡、小测、图鉴、对战、护照），尺寸 375×812。三个方向的布局、密度、比喻和颜色都不同；犀鸟都在。全部能用 WXML / WXSS 做出来，只有 B 的星图和点阵用到一块 canvas。

A 旅行手账B 词光夜航C 犀鸟闯关对比和建议

DIRECTION A旅行手账

把官网刚定下来的纸色、墨绿、深蓝绿、琥珀和宋体标题原样搬进小程序：首页是一张「今日车票」，护照页就是一页真护照，图鉴像词典的索引页。信息靠细线、字号和留白分层，不靠一堆卡片。它和官网是一家人，改动风险最小，学生一眼看得出这是给认真学语言的人用的。

借了什么

  • 词光：今日页「先温故，再知新」一张主卡一个按钮；图鉴按词频段 + 词性筛选；评分按钮下面写下次复习时间（FSRS）。
  • 墨墨背单词：列表密度高、一行一个词，记忆程度用小圆点表示。
  • 不背单词：例句是主角，词在句子里高亮。

配色和字体

纸 #f7f2e8墨绿 #1f5a43蓝绿 #123f45琥珀 #c46d1c印章 #b4472f墨 #1c2420

中文标题宋体（iOS 自带 Songti SC；安卓用 wx.loadFontFace 加载思源宋体子集，或退回系统黑体加粗），马来语 Georgia，编号等宽字体，正文苹方 15px。

DIRECTION B词光夜航

最贴近词光的一版：深色、安静、每屏只做一件事。首页就是一个数字和一个按钮；词卡是一张象牙色的卡片浮在夜色里；学会一个词，星图上亮一颗星。底色不用词光的藏青，改用官网的深蓝绿调暗，和品牌接得上。适合晚上在宿舍背词的学生，也最显「高级」；代价是气氛偏冷，游戏感最弱。

借了什么

  • 词光：象牙卡片 + 斜体衬线词、「学会一个，点亮一颗」的星图、图鉴按词频段和词性看、记忆牢固程度分布、未来 7 天复习量。
  • 不背单词：深色、专注、没有多余装饰。
  • 多邻国：排行榜只给你看「上一名差多少分」，压力来自身边的人，不是第一名。

马来语用 Georgia 斜体（卡面）和正体（正文），数字 Georgia，中文标题宋体，正文苹方 15px。只用纯色和细线，没有毛玻璃。星图和 500 词点阵各是一块 canvas 2d。

DIRECTION C犀鸟闯关

最大胆的一版：把每站 500 词切成 25 个小关，首页就是一条弯弯的闯关路，犀鸟站在你当前的关卡旁边。颜色直接取自犀鸟身上的橙、黄、墨黑和雨林绿，粗描边、实心投影，像贴纸。图鉴变成「集卡册」，每个词是一张卡，记得越牢星越多。它最能解决「功能太简单、没意思」，也最容易在微信里传开；代价是离官网的纸质编辑风最远，气质更年轻。

借了什么

  • 多邻国：一条路、一关一关走、连胜、每屏一个大按钮、答对有即时反馈。
  • 百词斩：大色块、选项是大方块，单手点得准。
  • 词光：图鉴的词频段 + 词性筛选，换成「集卡」的玩法；复习间隔仍然用 FSRS。

配色和字体

米白 #fff6e4喙黄 #ffc533冠橙 #f2622e雨林 #18a06a羽黑 #1b1d2a

全部用粗黑体（系统苹方 / 安卓思源黑体 800 字重），马来语和数字用粗的无衬线字，不用衬线。按钮是 2.5px 描边 + 实心下沿，按下时下沿收起，WXSS 直接能写。

对比和建议

方向首页的比喻密度和官网的距离开发量最适合
A 旅行手账一张今日车票 + 路线表中，靠细线分层最近，同一套颜色和字体最小：换样式为主，加一页图鉴想稳、想和官网统一
B 词光夜航一个数字 + 星图最低，每屏一件事中，颜色接得上，气氛不同中：两块 canvas，深色全套重做想要词光的安静和「高级」
C 犀鸟闯关一条闯关路高，色块大最远最大：关卡、等级、徽章、集卡要加后端字段想解决「太简单」、想传播

建议选 A 做底，把 B 和 C 里最值钱的三样搬进来：B 的「记得多牢 + 未来 7 天复习量」放进护照页，B 的星图做成图鉴页顶部的可切换视图，C 的「每站切成 25 小关」放进路线页。理由：A 和刚改好的官网是一家，犀鸟在纸色上最好看，改动主要在样式，现有页面结构基本不用动；「功能太简单」靠图鉴、FSRS 和小关来解决，不靠换一身皮。如果创始人更看重在学生之间传开，就选 C，但要接受它和官网是两种气质。
