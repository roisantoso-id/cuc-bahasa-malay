整体来看，这套「词光夜航」视觉方案已经彻底摆脱了传统背词工具的古板感，主题氛围和角色情绪都很到位，但在**微信小程序真实尺寸（375pt 宽 + 顶部胶囊 + 底部安全区）**和**信息对比度**上还有几处硬伤需要落地前修正。

---

### 1. 打分与总评
- **评分：7.6 / 10**
- **一句话总评：** 暗夜鎏金氛围与 3D 黏土犀鸟建立了很有记忆点的“出发→陪考→庆祝”情绪流，但缺少微信原生胶囊避让、底部安全区留白不足、局部灰字对比度过低，直接切图开发会在真机小屏上显得拥挤且易误触。

---

### 2. 最该改的 5 条

1. **三屏顶部：预留微信胶囊与退出入口（位置/层级）**
   - **问题**：第 2 屏的进度条和 `8 / 30` 紧贴刘海下方，真机上右上角会被微信小程序固定胶囊（约宽 87pt、高 32pt）直接遮挡 `8 / 30`；同时三屏左上角均缺少返回/退出图标。第 1 屏 `找到你的起点` 和第 3 屏犀鸟头冠也偏靠上。
   - **改法**：顶部统一留出 `状态栏 + 44pt` 导航区。第 2 屏左上角放 `×` 或 `<` 退出按钮，进度条和 `8 / 30` 下移到胶囊下方同一行（或缩至左侧安全宽度内），避免被微信原生组件盖住。

2. **三屏底部：拉高安全区留白，强化次要操作（大小/位置/颜色）**
   - **问题**：第 1 屏 `先跳过，从入门学起`、第 2 屏 `选你最确定的，不会就选不认识`、第 3 屏 `再测一次` 紧贴手机底部指示条，字号偏小、颜色过暗，且带细下划线显得像旧网页链接。
   - **改法**：主按钮距底部边缘至少留 `34–44pt`（覆盖底部安全区并留呼吸感）；次要文字链放到主按钮下方 `12–14pt` 处、字号提至 `13–14pt`、颜色提亮为浅灰青并去掉下划线，扩大点击热区至高度 `40pt` 以上，防止误触上滑手势。

3. **第 1 屏：弱化远端石阶，给犀鸟气泡减负（层级/大小/文字）**
   - **问题**：5 块发光石阶从上到下铺满中景，右下角 `入门` 石阶和犀鸟气泡距离过近、都在发光，前后层级打架；气泡里 `先测测你认识多少词，3分钟就好` 字号偏小且偏挤。
   - **改法**：压暗 `中高级`、`高级` 两块远景石阶的亮度与透明度做出景深，只让近景 `入门/初级` 清晰；气泡改为深色半透明微光描边底（不要和暖金主按钮/石阶抢亮度），字号调到 `13–14pt`，文案精简为 `测测你认识多少词，约 2 分钟`。

4. **第 2 屏：修正答题卡选中语义与长文本余量（元素/交互/文字）**
   - **问题**：选中 `A 食物` 时右侧出现 `✓`，在“测评”场景下容易让用户误以为“这题我答对了”，而实际上只是“已选中”；且白卡纵向较紧，若遇到长马来语词或双行中文释义会撑开高度。
   - **改法**：选中态不要用对勾 `✓`，改为金色加粗描边 + 浅金底色高亮（或小圆点），避免和“正误判分”混淆；选项高度统一设为 `48–52pt` 留出双行容错，词卡两侧距屏边保留 `20pt`；底部的 `不认识` 可移出白卡放到卡外下方，给卡内留出透气感。

5. **第 3 屏：拆开犀鸟与印章叠压，提亮高阶台阶（位置/颜色/层级）**
   - **问题**：`推荐 · 中级` 金色印章直接压在犀鸟右下侧翅膀上，背景又有大量彩色纸屑，剪影变碎、视觉显脏；下方 5 级台阶中 `中高级`、`高级` 几乎融进黑底，`◀ 从这里学` 夹在柱体窄缝里，375pt 屏上必然折行或重叠。
   - **改法**：把 `推荐 · 中级` 印章拿掉或改成独立金色徽章放到 `1,000` 正上方，让犀鸟完整独立展示；减少一半彩屑数量并降低饱和度。将 `中高级 / 高级` 柱体和文字提亮两个色阶；把 `从这里学` 改成悬在 `中级` 柱顶小旗旁的小标签，不要塞进柱间缝隙。

### 3. 吉祥物与组件的结合：优势与 375pt 真机落地风险

- **结合得好的地方：**
  - **情绪弧线完整**：第 1 屏站路旁拿地图引路 → 第 2 屏趴在答题卡顶边探头陪考 → 第 3 屏欢呼跃起，吉祥物不再是贴在角落的贴纸，而是和石阶、题卡真正发生空间互动。
  - **第 2 屏“探头扒卡”记忆点最强**：一双前爪搭在白卡上沿，把原本死板的四选一白卡片立刻变得有陪伴感。

- **真实小程序（375pt 宽 + 底部安全区）里会难做或显得乱的地方：**
  - **第 2 屏“身体在卡后、爪子在卡前”的图层穿插**：如果把整只鸟做成一张图，很难同时实现前后遮挡；必须拆成「头与身体（底层）+ 前爪透明图（顶层）」两张素材做绝对定位，否则在不同纵横比机型（如 iPhone SE 与全面屏）上卡片一居中或换行，爪子就会错位悬空。
  - **第 3 屏一屏装不下（纵深溢出风险）**：375pt 机型减去微信顶部导航（约 88pt）和底部安全区（34pt），可视高度常只有 **545–630pt**。第 3 屏同时塞了「大号欢呼犀鸟 + 1,000 大字 + 5 级台阶 + 说明文 + 主按钮 + 再测一次」，真机上极大概率要上下压缩甚至把主按钮挤出首屏，必须收紧犀鸟占位高度（建议占高不超过 170–190pt）或精简中间留白。
  - **第 1 屏横向碰撞**：375pt 宽度下，犀鸟 + 气泡 + `入门` 石阶横向并排很吃紧，若用户系统开了微信“大字体模式”，气泡会迅速拉高并撞上 `初级` 石阶。

### 4. 建议加的动效（克制、不花哨、适配小程序性能）

1. **进场（首屏 & 答题屏）**
   - **第 1 屏**：5 个石阶从 `入门` 到 `高级` 由下至上错峰淡入上浮（单块 `300ms`，间隔 `60ms`，`translateY 12px → 0`，`ease-out`）；犀鸟保持极轻缓的呼吸浮动（上下 `±4px`，`3.2s` 往返 `ease-in-out`）。
   - **第 2 屏**：答题卡由下微滑淡入（`260ms`），到位后延迟 `100ms` 犀鸟从卡背探头升起（`240ms`，`translateY 14px → 0`，无弹性过冲）。
2. **选中（点击选项 / 不认识）**
   - `110ms` 轻量按压缩放（`scale 1 → 0.98 → 1`），配合暖金边框与浅底色 `150ms` 过渡，同时触发一次轻触感反馈（`wx.vibrateShort({ type: 'light' })`）。
3. **答对 / 换题**
   - 选中后保留 `180–220ms` 停顿让用户看清自己选了哪项，随后卡内「单词 + 选项」整体向左轻滑淡出（`180ms`，`translateX 0 → -16px`），新题从右轻滑切入（`220ms`，`translateX 16px → 0`）；同时顶部进度条平滑推进 `280ms`。犀鸟仅在进度跨档时做一次轻微点头/眨眼（`240ms`），避免每题都跳动分散注意力。
4. **出结果**
   - 数字 `1,000` 做 `600ms` 缓出递增滚动（末段减速）；5 级阶梯柱从左到右依次升起（单柱 `280ms`，逐柱延迟 `70ms`），停在 `中级` 时柱顶小旗轻晃落定（`200ms`）；彩屑仅在页面进入时做一次 `800ms` 轻抛散开后静止，不要一直循环飘落。

### 5. 对比度不够、看不清或按钮太小的地方清单

- **文字看不清 / 对比度过低：**
  1. 第 1 屏底部 `先跳过，从入门学起`（暗底暗灰字，过细且发虚）。
  2. 第 2 屏底部 `选你最确定的，不会就选不认识`（深墨绿底上的暗灰小字，识别吃力）。
  3. 第 3 屏台阶右侧 `中高级`、`高级` 柱体与文字（几乎与背景融为一体），以及台阶下方的 `答错的词会优先推给你，学得顺会自动升一档`（字小且偏暗）。
  4. 第 3 屏 `推荐 · 中级` 印章叠加在彩色纸屑和犀鸟翅膀边缘上，背景干扰导致阅读变慢。
- **按钮太小 / 易误触：**
  1. **第 2 屏单词右侧的喇叭发音按钮**：视觉圆圈目测不足 `28pt`，建议视觉保持精致但透明点击热区扩到至少 `44×44pt`。
  2. **第 1 屏 `先跳过，从入门学起` & 第 3 屏 `再测一次`**：文字链可点高度窄且紧挨 iOS 底部横条，极易误触切出小程序。
  3. **第 2 屏顶部缺失退出按钮**：目前无返回/关闭按钮，且右上角 `8 / 30` 处于微信胶囊盲区。
