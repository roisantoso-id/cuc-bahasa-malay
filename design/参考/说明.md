# 视觉参考（2026-10-16 截图）

只学套路，不照抄。

| 产品 | 截图 | 值得学的 | 不学的 |
|---|---|---|---|
| Duolingo | duolingo.jpg | 一个固定吉祥物 + 一群角色，品牌辨识度极高；首屏只有一句话 + 一个大按钮 | 卡通满屏，对「大学团队研发」的权威感不利 |
| Busuu | busuu.jpg | 首屏右侧用多语言对话气泡说明「跟真人学」 | 紫蓝渐变 + 通用扁平插画，一眼模板 |
| Babbel | babbel.jpg | 衬线体 + 斜体强调词（*language*），米白底，成熟克制，像出版物 | 首屏语言选择对单语种产品没用 |
| Read Frog（GitHub 开源，1 万星） | readfrog.jpg | 大标题居中，四周漂浮各语言的小卡片，信息直观 | 白底大留白，内容少时显空 |
| LibreLingo（GitHub） | — | 官网已下线，跳过 | |
| Lingo（sanidhyy/duolingo-clone） | — | 只是 Duolingo 克隆，无新东西 | |

结论：
- 权威感学 Babbel（衬线 + 米白）；
- 辨识度学 Duolingo（一个固定角色或固定纹样贯穿全站）；
- 「这是马来语」要一眼看出：首屏放真实马来语句子，学 Read Frog 的漂浮卡片。
