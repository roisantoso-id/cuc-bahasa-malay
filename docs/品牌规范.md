# 品牌规范（学术出版物风格）

> 2026-10-18 改版：去掉 AI 生成的犀鸟插画和游戏化样式，改成学术出版物风格。官网和小程序都按这份规范做。

## 原则

- **只用真实素材**：张静灵老师的照片和著作封面、团队成员照片、RTM 直播截图和节目海报。不用 AI 插画、吉祥物或假的界面样机。
- **文字平实**：写事实，不喊口号，不用感叹号；数字都注明来源。
- **少装饰**：用细线分隔，不用卡片墙、彩色标签、投影、渐变、emoji。

## 名称与署名

- 产品名：**JomBelajar**（马来语「一起学吧」），后面可以跟「马来语」三个字。
- 署名：「中国传媒大学国际传播学院 马来语专业」，课程主持：张静灵副教授。不用校徽。

## 颜色

| 名称 | 色值 | 用在哪 |
|---|---|---|
| 深蓝 | `#14213d` | 主按钮、链接、数字、选中状态 |
| 金 | `#a8823a` | 编号、少量点缀 |
| 纸色 | `#f6f4ef` | 页面底色 |
| 墨 | `#1b1c1e` | 正文 |
| 灰 | `#55585e` / `#8b8e93` | 说明文字 |
| 线 | `#d9d4c8` | 分隔线；区块开头用 2px 墨色粗线 |
| 对 / 错 | `#2e6b4a` / `#a23b2a` | 只用在答题的正确和错误 |

## 字体

- 标题：系统宋体（`Songti SC` / `STSong` / `Noto Serif SC`）。
- 正文：系统黑体（`PingFang SC` / `Microsoft YaHei`）。
- 不加载 Google Fonts，以免国内访问被拦。

## 组件

- **按钮**：实色深蓝，圆角 3px（小程序 6–8rpx），没有投影。次要按钮用 1px 描边，或直接用文字链接。
- **区块**：用编号（01、02…）加宋体标题，上方一条细线。
- **列表**：用线分隔的行，不做成卡片。
- **人物**：照片加文字，两者之间不加框。
