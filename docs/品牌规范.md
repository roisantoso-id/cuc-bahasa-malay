# 品牌规范（方向 C · 犀鸟）

> 2026-10-16 选定，参考 `design/directions.html` 里的方向 C 和截图 `design/截图/方向C.jpg`。
> 官网和小程序都按这份规范做。要改颜色、字体或吉祥物，先改这里，再改代码。

## 名称

- 产品名暂用 **JomBelajar**（马来语「一起学吧」），沿用已上线的 bahasa.cn。
- 署名只用文字：「中国传媒大学马来语专业教师团队研发」。不写教授姓名，不放照片，不用校徽。

## 颜色

| 名称 | 色值 | 用在哪 |
|---|---|---|
| 主绿 | `#2fae66` | 主按钮、进度、正确、选中 |
| 主绿按下 / 投影 | `#22874e` | 主按钮底部投影 |
| 浅绿 | `#e7f7ee` | 答对背景、选中行 |
| 黄 | `#ffc83d` | 高亮、标题下划线、进行中的关卡 |
| 蓝 | `#4aa8ff` | 复习、信息提示 |
| 珊瑚红 | `#ff6b5a` | 连续打卡、答错、删除 |
| 底色 | `#fafaf7` | 页面背景 |
| 卡片 | `#ffffff` | 卡片背景 |
| 正文 | `#20242a` | 正文文字 |
| 次要文字 | `#8a9097` | 说明、时间 |
| 线 | `#e8e8e2` | 边框、分隔线、卡片底部投影 |

- 一屏只用一个主绿按钮。
- 黄、蓝、珊瑚红只用来标识状态或分类，不拿来大面积铺底。

## 字体

| 场景 | 字体 |
|---|---|
| 官网 | Nunito（800 / 900 字重，用于标题和马来语）+ 系统中文字体 |
| 小程序 | 系统字体（不加载外部字体，为了包体积和加载速度） |

- 马来语单词：粗体（800）。
- 中文释义：常规字重，用次要色。

## 组件

| 组件 | 规则 |
|---|---|
| 按钮 | 圆角 14px；高度 50px（小程序 96rpx）；字重 900；底部 4px 深色投影（`box-shadow: 0 4px 0 #22874e`）；按下时下移 4px、投影消失 |
| 次按钮 | 白底、2px 线色边框、底部 3px 线色投影 |
| 选项卡片（答题、单词） | 白底、2px 边框、圆角 14px、底部 3px 投影；选对变成浅绿底、绿边框；选错是珊瑚红边框 |
| 进度条 | 高 14px，全圆角，灰色底槽，绿色填充 |
| 卡片 | 圆角 18px；不叠阴影，靠边框和底部投影区分层次 |

**不要用**：渐变（除了标题下的黄色马克笔下划线）、emoji 当图标、毛玻璃、多层阴影。

## 吉祥物：小犀鸟

形象描述固定在 `design/gen-images.mjs` 的 `HORNBILL` 变量里，生成新图时**不要改写这段描述**，否则前后形象会不一致：

> A friendly cartoon rhinoceros hornbill: round chubby body in deep navy-black, white belly, big expressive eyes, a large curved orange-and-yellow beak with a red-orange casque on top, short wings that work like hands.

- **风格**：圆润、偏 3D 的扁平插画，底色 `#fafaf7`。
- **图里不放任何文字**：马来语和中文都由页面自己排版，避免模型写错字。

**已有姿势**（在 `design/生成图/c/`）

| 文件 | 姿势 | 用在哪 |
|---|---|---|
| `c-hero` | 挥手、拿手机 | 官网首屏 |
| `c-study` | 看书 | 学习、阅读 |
| `c-cheer` | 欢呼 | 完成一组 |
| `c-welcome` | 鞠躬欢迎 | 登录页 |
| `c-empty` | 看空箱子 | 空状态 |
| `c-pass` | 举奖杯 | 测试通过 |
| `c-fail` | 竖大拇指鼓励 | 测试未通过 |
| `c-checkin` | 盖打卡章 | 打卡 |
| `c-avatar` | 头像 | 默认头像 |
| `c-loading` | 抱书奔跑 | 加载中 |

小程序里的图要缩到宽 360px 左右、每张不超过 60KB，放进 `miniprogram/miniprogram/assets/`。
