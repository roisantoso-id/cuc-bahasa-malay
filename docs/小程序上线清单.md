## 三、后端 JomBelajar（你找维护人，我可以写好改动）

1. **微信登录**：新增 `POST /api/auth/wechat {code}`，服务器用 `code2session` 换 openid。
   - 需要小程序的 AppSecret，只放在服务器上；
   - 用户表加 `WeChatOpenId`；
   - 邮箱允许为空。
   - 小程序这边的调用已经写好：`api/auth.js` 里的 `wechatLogin`。
2. **刷新令牌**：现在只放在浏览器 cookie 里，小程序拿着不稳定。需要登录和刷新接口在返回内容里也带上刷新令牌，`/auth/refresh` 也能从请求体读取它。
3. **测试账号**：给我一个 bahasa.cn 的普通用户账号，用来联调；提审时也要给审核员一个账号。
4. **访问问题**：2026-10-18 从我这边访问 `https://www.bahasa.cn` 超时（命令行请求 15 秒没有响应）。请确认服务器是否正常、是否限制了境外访问。

## 四、隐私保护指引（草稿，可直接填）

| 收集的信息 | 用途 | 什么时候收集 |
|---|---|---|
| 邮箱 | 注册、登录、找回密码、接收验证码 | 注册或登录时 |
| 微信 openid（开通微信登录后） | 识别账号 | 微信一键登录时 |
| 昵称、头像、个人简介 | 在「我的」里显示 | 你主动填写或上传时 |
| 相册（选择图片） | 上传头像 | 你点「上传头像」时 |
| 剪贴板 | 复制媒体报道的视频链接 | 你点「复制链接」时 |
| 学习记录：单词学习和复习、打卡、试卷作答、视频观看进度 | 安排复习、显示学习进度 | 使用学习功能时 |

- 可以在「我的 → 账户安全」里删除账号，删除后资料会匿名化。
- 联系方式：小程序「我的 → 意见反馈」，或运营方邮箱（待填）。
