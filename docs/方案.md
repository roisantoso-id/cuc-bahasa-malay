# 马来语学习系统 · 项目方案

> 状态：初稿（2026-10-16）。标了「待定」的地方需要教授 / 团队确认。

## 1. 定位

| | 宣传官网 | 微信小程序 |
|---|---|---|
| 作用 | 让人知道、信任，然后打开小程序 | 真正学习的地方 |
| 谁会看 | 第一次听说的学生、家长、合作方、搜索引擎 | 已经在学的学生 |
| 主要动作 | 扫码 / 点链接打开小程序 | 每天学一课、复习单词 |
| 需要登录 | 不需要 | 微信一键登录（不用注册） |
| 更新频率 | 很少改，静态页面 | 课程内容持续增加 |

两类学生，同一个小程序，开始时选一次起点：

- **中国学生（零基础）**：从发音和拼读开始。马来语用拉丁字母，拼写基本照读音，入门快。
- **马来西亚华人（会说一些）**：口语已有基础，跳过发音，重点是正式书面语、语法和考试（如 SPM 马来文）。

## 2. 小程序功能（按上线顺序）

**第一版（能用）**
1. 微信登录，选起点（零基础 / 有基础）。
2. 课程：级别 → 课 → 课文（马来语句子 + 中文翻译 + 录音）。
3. 生词：每课生词，点开听发音。
4. 练习：选择题、听音选词、拼写。程序判对错，不用 AI。
5. 单词复习：按遗忘曲线安排每天要复习的词（记得 / 模糊 / 忘了）。
6. 我的：学习天数、已学课数、单词量。

**第二版（好用）**
- 跟读录音对比（先只做「录下来自己听」，评分以后再说）。
- 词典查询（马来语 ↔ 中文）。
- 老师端：看班级学生进度（网页后台）。

**以后再说**：AI 对话练习、付费课程、证书。

## 3. 技术方案

| 部分 | 选择 | 理由 |
|---|---|---|
| 小程序 | 微信原生小程序（JavaScript） | 不需要额外构建工具，交接给别人也看得懂 |
| 后端 | 微信云开发（云数据库 + 云存储 + 云函数） | 不用自己买服务器、不用给接口域名备案；登录直接拿 openid |
| 录音、图片 | 云存储 | 和小程序同一个环境，不用配置合法域名 |
| 课程内容录入 | 先用 JSON 文件导入；后面接云开发的「内容管理（CMS）」给老师在网页上编辑 | 第一版内容量小，先不做后台 |
| 宣传官网 | 纯静态 HTML + 一个构建脚本（`website/`） | 加载快、利于搜索，部署到任何静态托管都行 |
| 官网托管 | 国内：腾讯云 / 阿里云对象存储 + CDN（域名需 ICP 备案）| 有实体，可以备案 |

## 4. 数据（云数据库集合）

| 集合 | 存什么 | 关键字段 |
|---|---|---|
| `users` | 学生 | `openid`、`track`（`zero` / `heritage`）、`createdAt` |
| `courses` | 级别 | `id`、`title`、`order`、`track` |
| `lessons` | 课 | `courseId`、`order`、`title`、`sentences[]`（`ms`、`zh`、`audio`）、`words[]` |
| `words` | 生词 | `ms`、`zh`、`pos`、`audio`、`example` |
| `progress` | 学到哪 | `_openid`、`lessonId`、`doneAt`、`score` |
| `reviews` | 单词复习 | `_openid`、`wordId`、`box`（0–5）、`due` |

第一版课程内容放在小程序本地 `data/` 里，方便先跑通；内容定了再导入云数据库。

## 5. 上线要准备的（需要团队办）

1. **小程序账号**：用实体注册（企业 / 事业单位主体），完成微信认证，拿到 AppID。
2. **服务类目**：选教育相关类目。不同类目要的资质不一样（例如「在线教育」可能要办学许可或相关证明），注册时以微信后台显示的要求为准。
3. **小程序备案**：现在小程序上线前也需要做备案，在微信后台提交。
4. **隐私保护指引**：在小程序后台填写（会用到：微信登录、录音、学习记录）。
5. **官网域名 + ICP 备案**（如果官网放国内服务器）。
6. **内容**：教授提供课程大纲、课文、生词表；录音找母语者录制。

## 6. 排期（建议）

| 阶段 | 内容 | 时间 |
|---|---|---|
| 0 | 方案确认、拿到 AppID、定第一级课程大纲 | 第 1 周 |
| 1 | 官网上线（先放小程序码占位）；小程序跑通 1 级 3 课 | 第 2–3 周 |
| 2 | 小程序接云开发：登录、进度、单词复习 | 第 4–5 周 |
| 3 | 内容补齐第一级，找一个班试用 | 第 6–8 周 |
| 4 | 根据试用反馈改；提交审核上线 | 第 9–10 周 |
