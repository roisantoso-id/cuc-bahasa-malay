# 背单词 v1：上线步骤

> 2026-10-30。小程序端代码在 `miniprogram/`，云函数在 `miniprogram/cloudfunctions/`，种子词库在 `content/`。

## 一、你在微信开发者工具里做（约 10 分钟）

1. 把 `miniprogram/project.config.json` 里的 `appid` 换成你的小程序 AppID，或者直接把 AppID 发给我。
2. 点工具栏的「云开发」，开通一个环境，记下环境 ID，填进 `miniprogram/miniprogram/config.js` 的 `cloudEnv`。
3. 在云开发控制台 → 数据库，新建 5 个集合，并按下表设权限：

   | 集合 | 权限 |
   |---|---|
   | `scenes`、`words`、`teachers` | 所有用户可读，仅创建者可写 |
   | `students`、`progress` | 仅创建者可读写 |

4. 导入种子词库：`scenes` 集合 → 导入 → 选 `content/import-scenes.jsonl`；`words` 集合 → 导入 → 选 `content/import-words.jsonl`。
5. 在 `cloudfunctions/login`、`register`、`study` 上分别右键 →「上传并部署：云端安装依赖」。
6. 点「编译」，用真机预览试一遍：注册 → 选场景 → 背一组 → 复习。

## 二、种子词库要老师审核

- 96 个词都是 AI 起草的，状态是 `draft`（草稿）。场景页会提示「还在老师审核中」。
- 请张静灵老师或团队逐条看：词、释义、例句。改好后把 `status` 改成 `approved`。在后台操作，或者在控制台直接改都行。
- 一个场景只要有已审核的词，小程序就只显示已审核的那些；一个都没审核时，先显示草稿，方便试用。
- 发音：`content/audio/` 里是 Azure 马来语女声（Yasmin）生成的 96 个 mp3。接上云开发后，在后台用「生成发音」重新生成并上传到云存储；或者手动上传，把 fileID 填进每个词的 `audio` 字段。

## 三、第一版的范围

- 底部只有两个 tab：「背单词」「我的」。原来的阅读、测试、收藏等页面先不挂，文件都保留。等接上 JomBelajar 后端或者改成云开发后再打开。
- 学生注册填：姓名、学校、班级、基础（零基础 / 会说一些）、手机号，还要勾选同意隐私说明。
- 小程序后台「用户隐私保护指引」里要声明：手机号（手填）、剪贴板（复制链接）、学习记录。

## 四、网页后台

见 `admin/README.md`（单独一个会话在做）。上线需要：一条 DNS 记录 `admin.bahasa.cn` 指向 43.157.197.80；在服务器上建 `/etc/jombelajar-admin.env` 并填好 AppID、AppSecret、环境 ID 和管理员密码。
