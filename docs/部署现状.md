## 广州服务器加固（2026-11-03）

- **SSH**：只允许 `ubuntu` 用密钥登录。禁止密码登录、禁止 root 登录，最多试 3 次。配置在 `/etc/ssh/sshd_config.d/00-jombelajar-hardening.conf`。
- **fail2ban**：SSH 10 分钟内失败 5 次封 1 小时，再犯的封得更久，最长 1 周。
- **自动安全更新**：unattended-upgrades 已经开着。
- **内核网络参数**：`/etc/sysctl.d/90-jombelajar.conf`，包括 SYN cookies、反向路径过滤、禁止 ICMP 重定向等。
- **对外端口**：只有 22、80、443。数据库和后端只在 Docker 内网里。
- **容器**：
  - 全部 no-new-privileges；
  - caddy 和 api 去掉所有特权（caddy 只留绑 80/443 端口的权限），根文件系统只读。
- **文件权限**：`.env` 是 600，`backups/` 是 700。
- **还可以做**：数据库备份目前在同一台机器上，以后可以每天传一份到 COS 私有桶。轻量服务器控制台的防火墙只放行 22、80、443 就够了。
