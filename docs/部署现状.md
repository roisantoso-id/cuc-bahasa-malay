## 备案（要弄清楚）

- 绑定 COS 自定义域名时，腾讯云提示 bahasa.cn「没有备案」。
- 有两种可能：
  1. bahasa.cn 完全没有备案；
  2. 备案是在阿里云等其他服务商办的，腾讯云这边没有「接入」。
- 影响：www、admin、api 现在都在腾讯云大陆服务器上，目前能访问。但没有在腾讯云接入备案的域名，腾讯云随时可能拦截 80 和 443 端口。另外，微信要求小程序的 request 域名必须已经备案。
- 查法：在 https://beian.miit.gov.cn 查 bahasa.cn，看有没有备案号、主办单位是谁。
- 处理：
  - 已经备案、只是不在腾讯云：在腾讯云控制台办「接入备案」。服务器买满 3 个月以上才能办，大约 1–2 周。
  - 完全没有备案：以小程序主体的身份在腾讯云办首次备案。
  - 备案办好之前，如果接口被拦截，可以先在微信云开发里放一个云函数做转发。
