# 官网页面清单

加页面时三处一起改：这张表、`website/scripts/build.mjs` 里的 `NAV`（如要进导航）、页脚。

| 网址 | 中文名 | 干什么用 |
|---|---|---|
| `/` | 首页 | 介绍 + 小程序码（`#open`），主按钮「打开小程序」 |
| `/courses/` | 课程安排 | 两条路线的级别列表 |
| `/about/` | 关于我们 | 做什么、老师、运营方、联系方式 |
| `/privacy/` | 隐私政策 | 网站和小程序的信息处理说明 |
| `/404.html` | 找不到页面 | noindex，不进 sitemap |
