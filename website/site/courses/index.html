学什么

四个模块，分别练词汇、阅读、听力和检测。内容由中国传媒大学马来语专业教师团队编写，持续更新。

单词

  • 每组先记忆：看单词、听发音、回忆意思，再看释义和例句，按「重来 / 困难 / 良好 / 简单」打分。
  • FSRS 记忆算法按你的打分安排下次复习；到期的词出现在首页。
  • 记忆完可以练拼写，拼错的会再出现。
  • 收藏本、停止复习的词、每组数量和目标记忆保持率都可以自己管。

文章

  • 按主题分类的短文，可以搜索。
  • 有朗读录音的文章，可以边听边读，随时拖动进度。

视频

  • 情景对话视频，练真实语境的听力。
  • 自动记住看到哪里，下次接着看。

在线测试

  • 单选、判断、填空、听写四种题型。
  • 答案自动保存，交卷自动判分，逐题看解析。
  • 做错和没做的题自动收进错题本，重做对了就算掌握。
